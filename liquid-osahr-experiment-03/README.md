# Liquid-OSAHR Experiment 03

Query-conditioned residual trust for an OSAHR digital twin:

```text
T(q, I, r, h) → α ∈ {0, 0.25, 0.5, 1.0}
```

This is a descendant of [Liquid-OSAHR 02B](../liquid-osahr-experiment-02b/liquid-osahr-exp02b-stage-final/README.md). It does not retrain the residual CfC and does not overwrite 02B artifacts.

## What is implemented

- a typed trust-field object with explicit fallbacks;
- frozen fitting from the 02B 18-scenario calibration JSON only;
- confirmatory evaluation by selecting among already-run 02B arms;
- a labeled exploratory leave-one-scenario-out study on the confirmatory holdout.

## Run

```bash
python -m pytest -q
python scripts/run_experiment_03.py
```
